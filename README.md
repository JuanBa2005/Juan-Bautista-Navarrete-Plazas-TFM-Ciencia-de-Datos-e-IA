# TallerPredict — TFM de Ciencia de Datos e Inteligencia Artificial

Este repositorio contiene `docs/` (entregas académicas) y `tallerpredict/` (datos, SQL, scripts y resultados).

## Estado de las entregas

- [`docs/entregas/01_ideas_producto.md`](docs/entregas/01_ideas_producto.md): propuestas iniciales, incluida SmartStock Auto.
- [`docs/entregas/02_datos_y_preparacion.md`](docs/entregas/02_datos_y_preparacion.md): origen, preparación, calidad y dataset Gold.
- [`docs/entregas/03_machine_learning.md`](docs/entregas/03_machine_learning.md): experimento completo, baselines, Ridge, Random Forest, validación temporal, evaluación final y decisión para MVP.
- `docs/entregas/04_diseno_frontal_ux.md`: archivo presente sin contenido en la versión revisada; fase pendiente de documentar.

**Ruta correcta de trabajo:** entrar en `tallerpredict/` antes de ejecutar los comandos de Python o SQL. Consulta [`tallerpredict/README.md`](tallerpredict/README.md) y [`tallerpredict/VERSIONES.md`](tallerpredict/VERSIONES.md).

**Datos:** muestra parcial de un taller de Lorca, con nombre comercial confidencial. Revisar las condiciones de uso y publicación de la Entrega 02 antes de compartir registros de forma pública.
